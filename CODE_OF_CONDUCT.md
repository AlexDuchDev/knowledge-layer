# Code of conduct

We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) version 2.1.

## Reporting

- **General conduct concerns:** open a discussion with maintainers or email the contact address published on the main repository (replace with your org’s address when you fork).
- **Security vulnerabilities:** use [SECURITY.md](SECURITY.md) — do not file public issues with exploit details.

Maintainers will investigate reports promptly and proportionally.
